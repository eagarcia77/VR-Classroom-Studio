# Visual Identity — VR Classroom Studio

## Identity architecture

**Product:** VR Classroom Studio  
**Owner & Creator:** Eduardo Augusto García Rodríguez  
**Visual system:** Cosmic Academic Systems (descriptive identity language, not claimed as a registered mark)  
**Mascot / interface guide:** VRC-NOVA (internal character name)

## Brand idea

A learning system that treats every course as a navigable knowledge universe: objectives become constellations, activities become mission nodes, assessments become evidence beacons, and release governance acts as mission control.

## Logo

The production mark combines:
- a hexagonal system boundary;
- intersecting orbital paths;
- an open knowledge core;
- an XR visor silhouette;
- orbiting learning/data nodes.

Asset: `brand/vr-classroom-studio-mark.svg`

## Mascot: VRC-NOVA

VRC-NOVA is a friendly non-human XR learning guardian. Its visual language uses a floating body, visor, orbital knowledge core and asymmetric constellation nodes. The character is intended for onboarding, hints, accessibility guidance and mission-control status — not for autonomous grading authority.

Asset: `brand/vrc-nova-mascot.svg`

## Voice

Precise, exploratory, academic, calm and technologically advanced. Avoid claims that the software contains extraterrestrial technology. Terms such as cosmic, alien-inspired, holographic and orbital are visual/interaction metaphors.

## Accessibility

The logo has an accessible title/description in SVG. The mascot has an accessible title/description. Neither asset contains required instructional text; instructional meaning must remain available as HTML/text.
