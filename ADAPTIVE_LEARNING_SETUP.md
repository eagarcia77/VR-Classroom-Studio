# V17 Adaptive Learning Setup

Apply after V13–V16 in a dedicated VR Classroom Studio Supabase project.

V17 adds:
- `xr_competencies`
- `xr_mastery_snapshots`
- `xr_experience_statements`

These tables are optional analytics/authoring extensions. Blackboard SCORM playback does not depend on them.

The browser event stream is xAPI-shaped and intended as an interoperability-ready event model, not as a replacement for a certified Learning Record Store. If an LRS is introduced later, map and validate statements against the target profile before transmission.
